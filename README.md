# ВИТОК — лендинг индивидуальной школы циклических видов спорта

Статический сайт без сборки, без бэкенда и без внешних запросов.
Открывается двойным щелчком по `index.html` или любым локальным сервером.

## Структура

```
index.html               лендинг
privacy.html             политика конфиденциальности
robots.txt               правила индексации
sitemap.xml              карта сайта
assets/css/style.css     все стили
assets/js/main.js        хедер, меню, FAQ, форма, плавные якоря
assets/fonts/            локальные woff2 (Cormorant Garamond + Manrope) и fonts.css
assets/img/              фотографии (og.jpg — превью для соцсетей)
assets/favicon.svg       иконка сайта
tools/rename.py          смена названия и домена
```

Секции лендинга по порядку: `#audience`, `#deficit`, `#parallels`,
`#versus` (почему не зал), `#disciplines`, `#method`, `#result`,
`#formats`, `#about`, `#principles`, `#faq`, `#contact`.

Локальная проверка:

```bash
python3 -m http.server 8080
# затем http://localhost:8080
```

## Принципы, которые заложены в вёрстку

- **Ноль внешних запросов.** Шрифты, стили, скрипты и картинки — только с этого домена. Проверяется в DevTools → Network по фильтру «Third-party».
- **Форма без сервера.** Заявка собирается в браузере, показывается в `<pre>`, дальше — «Скопировать», «Открыть Telegram» или `mailto:`. Никаких запросов при отправке.
- **Без аккаунтов и куки-баннеров.** Нет аналитики, нет localStorage, нет трекинга — поэтому и баннер не нужен.
- **Доступность.** Скип-ссылка, `aria-expanded` у бургера и аккордеона, фокус-стили, `prefers-reduced-motion` отключает анимации появления.
- **Адаптив.** Три точки перелома: 1080px, 900px, 640px. Блок дисциплин на узких экранах становится одноколоночным с соотношением 16:10, секция «почему не зал» — из двух колонок в одну.

## Публикация

Сайт статический: бэкенд не нужен, база не нужна.

### Где сайт живёт сейчас

**https://arsenbrsoyan987-eng.github.io/**

Хостинг — GitHub Pages, бесплатный, без VPN и без ограничений по географии.
Публикация выполняется двумя командами из этой папки:

```bash
git add -A
git commit -m "описание изменений"
git push pages main
```

Через 30–60 секунд изменения появляются на сайте. Обновлять ничего вручную не нужно.

Два remote в этом репозитории:

| Remote | Куда ведёт | Зачем |
|---|---|---|
| `origin` | `github.com/arsenbrsoyan987-eng/vitok` | рабочая копия исходников |
| `pages` | `github.com/arsenbrsoyan987-eng/arsenbrsoyan987-eng.github.io` | то, что реально отдаётся посетителям |

### Свой домен вместо github.io

Когда купите домен, он подключается к тому же репозиторию:

1. В настройках репозитория `arsenbrsoyan987-eng.github.io` → Settings → Pages →
   Custom domain вписать домен.
2. У регистратора добавить DNS-записи, которые покажет GitHub:
   для корневого домена — четыре `A` на `185.199.108.153`, `185.199.109.153`,
   `185.199.110.153`, `185.199.111.153`; для `www` — `CNAME` на
   `arsenbrsoyan987-eng.github.io`.
3. Дождаться проверки DNS и включить «Enforce HTTPS».
4. В файлах сайта заменить адрес: `python3 tools/rename.py --domain "ваш-домен.ru"`,
   затем закоммитить и запушить.

### Смена названия и домена

Название и домен прописаны в шести файлах. Менять вручную не нужно — есть скрипт:

```bash
# посмотреть, что изменится
python3 tools/rename.py --brand "ВИТОК" --domain "vitok.ru" --dry-run

# применить
python3 tools/rename.py --brand "ВИТОК" --domain "vitok.ru"

# только домен, без смены названия
python3 tools/rename.py --domain "vitok.ru"
```

Скрипт трогает `index.html`, `privacy.html`, `README.md`, `assets/js/main.js`,
`robots.txt`, `sitemap.xml` и заменяет точные вхождения, поэтому повторный
запуск ничего не ломает. После смены домена проверьте в `index.html` строки
с `canonical`, `og:url`, `og:image` — там должен стоять новый адрес.

Домен также указан в `robots.txt` (директива `Sitemap`) и в `sitemap.xml`.

### Что отдаётся поисковикам и мессенджерам

| Файл | Назначение |
|---|---|
| `robots.txt` | разрешает индексацию сайта, закрывает `privacy.html`, указывает карту сайта |
| `sitemap.xml` | карта сайта из одной страницы |
| `assets/img/og.jpg` | картинка 1200×630 для превью ссылки в Telegram, WhatsApp, соцсетях |

Превью ссылки задаётся метатегами `og:*` и `twitter:*` в `index.html`.
После смены домена или картинки мессенджеры показывают старое превью из кеша —
обновляется через отладчик: Telegram (`@WebpageBot`), Facebook Sharing Debugger,
VK. Достаточно отправить ссылку заново после сброса кеша.

### Проверка на своём компьютере и в локальной сети

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

- на этом компьютере: `http://127.0.0.1:8080`
- с телефона в той же Wi-Fi сети: `http://<IP-компьютера>:8080`
  (IP смотрится командой `ipconfig getifaddr en0`)

### Временная ссылка без хостинга

Постоянный адрес уже работает, но если нужно показать сайт до публикации правок,
поднимается туннель на локальный сервер:

```bash
cloudflared tunnel --url http://127.0.0.1:8080 --no-autoupdate
# если провайдер режет QUIC:
cloudflared tunnel --protocol http2 --url http://127.0.0.1:8080 --no-autoupdate
```

Адрес вида `https://<случайное-имя>.trycloudflare.com` живёт, пока запущен
туннель и включён компьютер. Для постоянного адреса используется GitHub Pages.

## Служебные файлы

В папке только файлы сайта — черновики подбора и обработки фотографий удалены.
`tools/rename.py` — единственный служебный скрипт; на хостинг его заливать не нужно.
Скрытые файлы `.DS_Store` (создаёт Finder) к сайту не относятся и на хостинг не нужны;
`.gitignore` исключает их из репозитория.

Репозиторий на GitHub тоже содержит только файлы сайта, поэтому GitHub Pages
отдаёт папку как есть. `README.md`, `tools/` и `.gitignore` посетителям не видны —
это не страницы сайта.
